                      STUDENT RECORD MANAGEMENT SYSTEM
Here I Developed a menu-driven Student Record Management System in C using a singly linked list, dynamic memory allocation, modular programming, searching, sorting, and file handling
This Project is designed to manage student records efficiently using a dynamically allocated single linked list.

Features
->Add student Records
->Delete records by rollnumber or name
->Display all records
->Modify records by rollnumber,name or percentage
->Sort records by name or percentage
->Reverse the linked list 
->Delete all records
->Save and load records using student.dat
->Input validation and proper memory management

Concepts Used
->C programming
->Structures & pointers
->Single Linked List 
->Dynamic Memory Allocation
->File Handling
->Searching & Sorting
